## ディープワーク・ブロックスケジューラー

Cal Newport 式の集中作業時間をブロック単位で管理し、週次合計時間トレンドをヒートマップで追跡する生産性ツール。

### 機能
- 6:00〜24:00 を1時間ブロックで表示し、クリックで「ディープワーク可」「会議/通知有」「休憩」をトグル
- 連続ディープワークブロックを「セッション」として自動計算・表示
- 本日のディープワーク目標時間スライダー（1〜6時間）と達成率プログレスバー
- 実績入力（実際に何時間集中できたか）の保存
- 過去7日間のディープワーク時間ヒートマップ（緑のグラデーション）
- localStorage による日次記録の自動保存（最大30日分）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage（日次ブロック・実績記録）
